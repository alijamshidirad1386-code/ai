کاربر درخواست مقایسه مکانیزم Self-Attention با متدهای سنتی مثل RNN و LSTM و پیاده‌سازی فرمول سافت‌مکس برای کیو، کی و وی در NumPy دارد.
۱. تحلیل ضعف‌های بازگشتی (Gradient Vanishing و عدم امکان پردازش موازی).
۲. توضیح فرمولاسیون ماتریسی Scaled Dot-Product Attention: $Attention(Q, K, V) = softmax(\frac{QK^T}{\sqrt{d_k}})V$.
۳. نوشتن اسکریپت بهینه پایتون بدون لایبرری‌های حجیم.

در معماری‌های سنتی NLP مانند RNN و LSTM، ورودی‌ها به صورت گام‌به‌گام و ترتیبی (Sequential) پردازش می‌شدند که دو ایراد عمده داشت: اولاً مانع از موازی‌سازی فرآیند آموزش روی پردازنده‌های گرافیکی (GPU) می‌شد، و ثانیاً در توالی‌های طولانی داده، «فراموشی ارتباطات دوردست» رخ می‌داد.

مکانیزم Self-Attention اجازه می‌دهد تا مدل به تمامی توکن‌های جمله به صورت همزمان نگاه انداخته و میزان اهمیت و ارتباط معنایی هر کلمه را نسبت به سایر کلمات با ماتریس‌های Q (پرسش)، K (کلید) و V (ارزش) وزن‌دهی کند.

python (NumPy Self-Attention) 
import numpy as np

def scaled_dot_product_attention(Q, K, V):
    d_k = Q.shape[-1]
    scores = np.matmul(Q, K.T) / np.sqrt(d_k)
    # Softmax normalization across last dimension
    attention_weights = np.exp(scores) / np.sum(np.exp(scores), axis=-1, keepdims=True)
    output = np.matmul(attention_weights, V)
    return output, attention_weights

# تست خروجی با ابعاد ساختگی:
Q = np.random.rand(4, 64)
K = np.random.rand(4, 64)
V = np.random.rand(4, 64)
out, weights = scaled_dot_product_attention(Q, K, V)
print("Shape of Context Output:", out.shape)
